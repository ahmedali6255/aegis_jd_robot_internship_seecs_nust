# aegis_jd_robot_internship_seecs_nust
AEGIS-JD's Object Detection &amp; PID Tracking module — voice-commanded object search for the EZ-Robot JD Humanoid. Uses YOLOv8 for real-time detection, Gemini API for language reasoning and location description, and a custom PID controller for smooth pan/tilt camera centering. Individual contribution from a 5-member robotics internship team.
